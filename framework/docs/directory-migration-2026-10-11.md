根目录执行 install:all、check:all、example:check/build/start/dev、docs:dev/build/check/test:browser。SDK 的 build、check、test、coverage、消费者、探针与压测命令进入 framework 执行。三个工程各自使用锁文件和依赖，示例与网站继续精确安装 npm dou-bot@0.7.0。

普通源码真实探针读取 framework/.env，附件探针明确读取 example/.env，离线入口不加载凭证。根目录和各工程的忽略规则继续排除真实环境文件与生成物。本机没有安装在用户目录的 dou-bot 技能链接，本轮只更新仓库技能路径及说明。
