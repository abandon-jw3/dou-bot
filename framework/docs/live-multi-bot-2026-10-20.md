# 双机器人 WS 实测（2026-10-20）

**本轮通过。** 两个真实 QQ 机器人、本机 WS 接入、新专用 PostgreSQL 17.6；QQ 客户端收件结果由用户逐项确认。

## 实测结果

| 项目                  | 结果                                                                |
| --------------------- | ------------------------------------------------------------------- |
| A、B 私聊与群聊回复   | 均收到，账号标记正确                                                |
| 同一个真实群的 OpenID | 两个机器人取得不同的群 OpenID                                       |
| 群地址持久化          | 数据库读回两个机器人、各一个群地址；重启 A 前后共四次路由检查均正确 |
| 本机 WS 触发主动发送  | 第 1 轮 A、B 均收到；发送者正确                                     |
| 停止 A                | A 返回 BOT_UNAVAILABLE；B 继续主动发送并回复指令，没有替 A 发送     |
| 恢复 A                | 第 3 轮 A、B 均收到；A 重新接收并回复指令                           |
| 共享服务              | 停止、恢复 A 后均保留原实例                                         |
| 退出清理              | 两个验收实例关闭，进程退出码 0；数据库侧框架连接数归零              |

- 共记录 8 次指令回复；三轮主动发送共 6 次尝试，5 次成功、1 次为停止 A 后预期的 BOT_UNAVAILABLE。
- 群地址始终保留 appId + groupId，没有合并不同机器人的 OpenID，也没有跨机器人替发。
- 数据库查询独立读回了持久化结果；没有使用已停用的 TEST_DATABASE 配置。
