# 1.0.0-rc.1 候选发布

状态：**已于 2026-11-01 02:55:47（Asia/Shanghai）发布到 npm `next`**，`latest` 保持 0.8.0。发行提交 `6868506` 的全部 CI 通过后，上传了已验证的同一份 tarball。

## 变化

- 命令默认忽略未使用的普通参数。例如“诛恶 梦江南 121”匹配服务器“梦江南”，忽略 121。
- Rest 仅在业务需要读取剩余文字时声明；Args 与 Context 保留完整输入。
- 缺参、类型、范围、重复匹配、歧义及未知选项仍报错。普通文字不再因为无人接收而阻止处理器执行。
- 随附技能按使用场景组织，说明命令、附件、上下文、ORM、多账号通知和测试。
- 不新增 API、依赖或配置；TypeScript 5.9.3、公开契约 2.0、运行依赖和默认并发保持不变。

## 升级

```sh
npm install --save-exact dou-bot@1.0.0-rc.1
```

- 可以删除仅用于接收并忽略普通余参的 Rest 参数；需要读取正文的 Rest 保留。
- `--detail false` 仍表示开启 detail，false 是普通文字；关闭开关使用 `--detail=false`。
- 若业务要求拒绝额外正文，可使用 Rest 读取后自行判断。
