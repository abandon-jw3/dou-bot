# 0.8.0 公网 Webhook 验收

日期：2026-10-13（Asia/Shanghai）。本轮使用 npm 的 dou-bot 0.8.0，在独立 Linux 服务上验证公网 HTTPS 与真实 QQ 收发，不使用 SDK 源码依赖。验收通过，临时服务已停止；结构化证据见 [验收记录](webhook-validation-2026-10-13.json)。

同日后续已完成 [故障与恢复实测](webhook-recovery-validation-2026-10-13.md)。下文和原始 JSON 保留本次基础收发阶段的范围，不回写为当时已测试重试或崩溃恢复。

## 接入与部署

- 回调地址：`https://qq.fineiii.xyz/dou-bot/qq`，公网端口为 443。
- Nginx 仅将该路径转发至 `127.0.0.1:31080`；健康检查不对公网开放。
- Node.js 24.21.0 独立安装，保留服务器原有 Node.js 22.21.1 与站点配置。
- 运行环境为 Debian 12、Nginx 1.22.1，验收程序由 TypeScript 5.9.3 编译。
- HTTPS 证书签发、外部校验与续期模拟通过；续期后的 Nginx 重载脚本已验证。
- 机器人凭证独立保存，日志不记录用户 ID、群 ID、消息正文、附件 URL 或凭证。
- 服务使用独立的动态用户，仅绑定一位私聊测试用户与一个群聊测试会话。单次窗口为 30 分钟，不设开机自启。

[QQ 官方文档](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/interface-framework/event-emit.html#webhook方式)要求 HTTPS，允许的公网回调端口为 80、443、8080、8443；内部转发端口不填入 QQ 后台。

## 已验证的链路

- 本地私聊、群聊夹具覆盖归一化、身份、上下文、按钮、对话、图片和 DOCX 路由；服务器另执行两组离线启动与命令检查。
- 13 项公网协议检查通过：请求方法、隐藏健康接口、HTTPS 跳转、缺失或错误签名、错误 AppID、过期时间戳、正文篡改、JSON 格式、请求大小、有效签名事件及地址验证响应。
- QQ 开放平台的回调地址验证通过，服务器收到签名请求并返回 200。
- 私聊、群聊的文字命令均收到真实签名回调，QQ 接口返回发送成功，用户确认客户端收到回复。
- 两场景中，Slot.normalize 将“双梦”转换为“梦江南”，身份参数与上下文一致；Guard、ContextValue 和 state.get 共享本次执行的数据。
- 私聊、群聊按钮点击均收到回调并回复，用户确认成功。
- 私聊、群聊 prompt 收到回答后成功回复，上下文数据保持一致，等待项归零；用户确认成功。
- 私聊、群聊的“指令与一张图片同条发送”均通过，用户确认图片计数回复。
- 私聊、群聊直接上传指定名称的 DOCX 均命中附件处理器，用户确认回复；本轮未下载或解析文件内容。
- 私聊取消与群聊 45 秒超时均正确结束并回复，用户确认提示正常。

真实服务运行于北京时间 01:39:53～01:49:04，约 9 分 11 秒；接纳 18 个真实消息及交互事件，框架错误、事件失败和容量拒绝均为 0。关闭后队列、等待项、去重缓存和回复缓存均归零，进程退出码为 0，内部端口不再监听。

公网协议的合成请求与真实 QQ 客户端确认分别记录，不能互相替代。上述结果限于本次机器人、测试用户与测试群。

## 运行与停止

在部署服务器执行：

```sh
systemctl status dou-bot-validation.service
journalctl -u dou-bot-validation.service --no-pager -o cat
systemctl stop dou-bot-validation.service
```

- 到期或停止时关闭 HTTP 接入与 SDK，最终快照保存于服务的 StateDirectory。
- 本次已经主动停止服务；QQ 后台地址与 HTTPS 配置保留，继续接收业务消息前需要启动正式应用。
- Nginx 的独立配置位于 `/etc/nginx/dou-bot-validation.conf`；修改前已保存主配置备份。
- 本轮不是容量压测或多日生产运行。真实平台重试、跨重启重投、长时间业务观察及 1.0 RC 验收仍需单独安排。
- 探针与原始脱敏记录保存在被 Git 忽略的 `framework/work/production-validation/2026-10-13-cf13e5/`；本轮不修改 SDK 版本，不发布、提交或推送。
