## 交付内容

- AppFactory 创建共享应用，多个机器人分别使用 WS/Webhook 接入。
- MessageSender、BotManager 明确选择账号；完整目标包含 appId、场景和账号下的 OpenID。
- PostgreSQL 是必需依赖，提供共享连接池、SQL、事务、群地址与归属持久化；初始化显式执行。
- 入站与出站独立预算，账号间公平调度；按账号停止与恢复，不重建共享服务。
- diagnostics 提供有界的阶段指标、采样和导出；默认关闭。
- Webhook 异步验签、数据库断连/关闭处理、资源回收和高频路径优化。
- 命令、附件、身份、Guard、按钮、prompt 和上下文中间件继续由业务模块使用。
- 用户手册、业务示例和 skill 已适配；业务自行选择 ORM，本包不增加 ORM 依赖，也不宣称已完成 ORM 联调。

## 版本与边界

- 公开源码契约为 **2.0**，不代表 npm 版本为 2.0.0。
- 此候选与 npm 0.8.0 的创建入口、共享 DI、账号配置及应用快照不兼容；从新项目使用。
- Node `>=24.0.0 <25`，TypeScript 5.9.3，MIT。
- 运行依赖固定为 pg/@types/pg 8.23.1、reflect-metadata 0.2.2、ws 8.22.0。
- 每个账号的 OpenID 独立；不合并真实群，不自动换机器人补发。
- 消息队列、去重、冷却和 prompt 在内存中；进程崩溃后不恢复未完成任务，不承诺跨进程恰好一次。
- RC 仍可能调整 API；正式版的兼容与弃用承诺在完成 RC 试用后确定。
