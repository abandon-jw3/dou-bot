# 生命周期

## 创建、启动、关闭

`BotFactory.create()` 检查配置、模块图和路由，构造依赖并执行初始化钩子。业务自己的初始化钩子可能创建资源；框架的 QQ 接入由 `app.start()` 启动。

`await app.close()` 停止接纳新事件，结束等待中的对话，按总期限排空或取消受管工作，并销毁框架创建的资源。关闭之后不能再次启动同一个实例；需要新建应用。

## 协作取消

上下文中的 `signal` 可传给业务 fetch 等支持取消的 API。框架可以取消受管等待和请求，但不能硬终止无限循环或不配合 signal 的 JavaScript。

命令、按钮或原始事件处理器结束后，不要继续复用旧上下文发送消息。延迟任务应保存必要的业务数据，而不是保存整个 ctx。

## 退出处理

快速开始的入口捕获 SIGINT/SIGTERM 并等待 close；Windows 终端按 Ctrl+C 可以使用该路径。任务管理器强制结束、系统掉电等场景不能保证钩子完成。部署时优先使用可给予退出期限的进程管理方式。
