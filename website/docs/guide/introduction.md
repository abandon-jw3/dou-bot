# 框架介绍

dou-bot 是用于 QQ 官方群聊和私聊的轻量 TypeScript 机器人框架。

## 能做什么

| 功能                         | 入口                                                 |
| ---------------------------- | ---------------------------------------------------- |
| 接收命令、校验参数、生成帮助 | [命令](./commands.md)、[参数](./parameters.md)       |
| 接收图片、视频、语音和文件   | [附件](./attachments.md)                             |
| 读取发送者、群和角色         | [身份参数](./identity.md)                            |
| 限制用户权限和调用频率       | [访问限制](./access.md)、[Guard 与冷却](./guards.md) |
| 发送文字、图片和按钮菜单     | [消息](./messages.md)、[按钮](./buttons.md)          |
| 询问用户并等待下一条输入     | [多轮对话](./prompts.md)                             |
| 不连接 QQ 测试业务           | [离线测试](./testing.md)                             |

- 执行前准备业务数据：[上下文中间件](./context.md)。
- 观察队列、缓存与延迟：[容量监测](./capacity.md)。

## 开始使用

- 示例使用 TypeScript **5.9.3** 和 ESM，已配置装饰器与编译脚本。
- 运行环境：Node.js **24.x**，最低 **24.0.0**；教程使用 **24.21.0**。
- 连接 QQ 前，准备 AppID、AppSecret 及相应的群聊或私聊权限。
- 从 [快速开始](./quick-start.md) 创建项目；没有凭证时先做离线测试。

## 选择接入方式

| 方式                         | 需要准备                   |
| ---------------------------- | -------------------------- |
| [WebSocket](./ws.md)（默认） | 常驻进程，无需公网回调地址 |
| [Webhook](./webhook.md)      | QQ 可访问的 HTTPS 回调地址 |

两种方式使用同一套业务模块。

## 使用边界

- 面向 QQ 官方群聊和私聊，不支持 QQ 频道或 Koishi 插件。
- 图片、按钮和普通群消息的可用性取决于 QQ 账号权限。
- 队列、去重、冷却和对话保存在进程内，重启后重置。
- PostgreSQL 是必需依赖，框架持久化群地址和归属；业务表、文件处理和定时任务由自己的服务负责。
- 多账号与发送选择见 [多机器人](./multi-bot.md)，性能定位见 [观测指南](./diagnostics.md)。
- 升级前查看 [更新日志](../changelog.md)；无回复时查看 [排错指南](./troubleshooting.md)。
