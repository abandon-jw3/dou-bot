# 框架介绍

dou-bot 是面向 QQ 官方机器人群聊和私聊的 TypeScript 装饰器框架。它采用模块、控制器、依赖注入和 Guard 组织业务，运行时的直接依赖为 reflect-metadata 与 ws。

## 适用范围

- QQ 官方群聊、私聊，以及对应的消息和按钮事件。
- 每个应用实例选择 WS 或 Webhook 接入。
- Node.js、ESM、传统 TypeScript 参数装饰器；本手册统一使用 TypeScript 5.9.3。
- 进程内队列、去重、冷却和 prompt。重启后这些状态会重置。

不包含 QQ 频道业务、Koishi 插件兼容或运行时热更新。业务数据库、定时任务和外部服务由应用自己选择、注入与管理。

## 一条消息怎样被处理

QQ 投递事件后，框架识别会话与命令，依次执行模块、类和方法的 Guard，再绑定参数、占用冷却，最后调用处理器。命令返回字符串或消息对象时自动回复。

原始 `@On()` 观察器独立执行。被 prompt 消费的回答属于已有对话，不会作为新命令再跑一遍 Guard。

## 需要准备什么

你需要能使用 npm 和基础 TypeScript。如果准备连接 QQ，还需要在 QQ 机器人平台取得自己的 AppID、AppSecret，并确认机器人具备对应群聊或私聊能力。先看 [快速开始](./quick-start.md)；没有凭证时可以用 [离线测试](./testing.md)。

## 版本和验收边界

本文档只描述已发布的 **0.6.0**。不要把开发仓库中的未发布类型、内部路径或其他同名 npm 包当作这个版本的 API。

WS 的群聊、私聊、图片、原始 Markdown 和普通按钮已有实机验证。2026-10-06 补充完成 macOS 下的文字、Markdown 与普通按钮收发，并在本次机器人和测试群中核对群主、管理员、普通成员的角色字段、命令权限及管理者回调按钮的允许/拒绝路径，详见 [访问限制](./access.md#实机验收范围)。这些实测结论限于对应账号与测试会话。Webhook 已完成本地 HTTP 与签名验证，公网 QQ 回调和多日稳定性仍待专项验收。
