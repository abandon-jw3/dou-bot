在自己的项目根目录执行 `npx tsc -p tsconfig.json`，再执行 `node --env-file=.env dist/main.js`。

| 你发送                                | 机器人行为                   |
| ------------------------------------- | ---------------------------- |
| `/收图` 与 1～4 张图片同条发送        | 回复图片数量                 |
| `/上传 video`，等待提问后单独发送视频 | 接收一个视频并引用新消息确认 |
| `/上传 audio`，等待提问后发送音频     | 接收一个音频                 |
| `/上传 file`，等待提问后发送文件      | 接收一个文件                 |
| 直接发送“报告_20261007.docx”          | 文件名匹配后自动确认接收     |

追问时可以发送“取消”。类型或数量不符时，示例提示并结束，不自动重复提问。下一条输入由当前 prompt 独占，即使它的文件名也满足自动路由条件，也不会触发第二次接收。

这些回复确认的是消息元信息。将选择后的附件交给自己的服务下载、验证并处理；平台必须实际投递该附件事件。更多筛选和权限规则见 [接收图片与文件](../guide/attachments.md)。
